# 初中生学习工作台

移动端优先的单页学习应用，护眼淡盐配色，适合初一学生使用。

## 功能模块

- **首页仪表盘**：今日任务、番茄专注时长、错题待复习数、背诵提醒、积分
- **每日计划**：按科目（语文/数学/英语/物理）添加任务并勾选完成
- **智能错题本**：拍照 OCR 识别 + AI 结构化解析；按科目/知识点/错因筛选；艾宾浩斯复习提醒；支持标记已掌握
- **背诵打卡**：艾宾浩斯背诵计划（1/2/4/7/15/30/60 天）
- **学习统计复盘**：7 天专注柱状图、错因分布、薄弱知识点 TOP5、自动生成改进建议

## 本地打开

双击 `初中生学习工作台.html` 即可在浏览器中使用，数据保存在浏览器 localStorage，无需联网（Tailwind CDN 断网时由内嵌 CSS 兜底）。

手机使用：把 HTML 文件传到手机，用浏览器打开；拍照录入错题功能会调用手机摄像头（`capture="environment"`）。

## 拍照录入错题流程

1. 点击「拍照录入错题」→ 调用手机摄像头拍照，或从相册选图
2. 图片在前端压缩后预览
3. 点击「开始识别并解析」→ OCR 识别试卷文字与手写答案
4. AI 解析为固定结构，人工确认/修改后保存

AI 解析固定输出结构：

- 【原题】
- 【学生作答】
- 【参考答案】
- 【涉及知识点】（精准到初一考点，如：一元一次方程移项、一般现在时句型）
- 【错误原因分析】（概念不清 / 计算粗心 / 审题漏条件 / 步骤不规范 / 不会审题）
- 【学习建议】（简短可执行）
- 【举一反三练习题】（2～3 道同考点新题，附答案）

## OCR / AI 配置

页面点击顶部「🌿 学习工作台」标题或统计页底部按钮进入设置：

- **演示模式（默认）**：无需后端，直接体验完整流程，内置数学/英语/语文示例解析
- **自定义 HTTP 接口**：填入 OCR 和 AI 接口地址，前端 POST JSON 调用
  - OCR 接口：请求 `{image: base64}`，返回 `{text: "..."}`
  - AI 接口：请求 `{prompt, text}`，返回上述结构化 JSON
- **CloudBase 云函数**：填入环境 ID，调用 `ocrRecognize` 和 `analyzeMistake` 云函数

## CloudBase 云同步扩展

1. 在页面 `<head>` 引入 CloudBase JS SDK：
   ```html
   <script src="https://static.cloudbase.net/cloudbase-js-sdk/latest/cloudbase.full.js"></script>
   ```
2. 在设置中填入环境 ID（env）
3. 部署云函数 `syncData`，约定：
   - 入参 `{action:'up', data}` → 保存数据，返回 `{ok:true}`
   - 入参 `{action:'down'}` → 返回 `{data: {...}}`
4. 点击「上传备份」/「下载恢复」，或勾选自动同步（每次修改后自动上传）

## 技术栈

HTML + TailwindCSS（CDN）+ 原生 JS，单文件，localStorage 本地存储，预留 CloudBase 同步接口。
